Inputs

Listing card

Fields map 1:1 to RESO/IDX: ListPrice, ListingId (MLS#), BedroomsTotal, BathroomsTotalInteger, LivingArea, UnparsedAddress, PropertySubType, SubdivisionName, DaysOnMarket, StandardStatus. Badge color encodes status: gold new, navy open house, green price drop, slate pending, gray sold.

Layout & spacing

  • Content max-width 1200px (1400px for listing results), 24px side padding.
  • Section rhythm 72–80px; card padding 16–28px; grid gap 20–22px.
  • All grids use repeat(auto-fit, minmax(min(100%, Npx), 1fr)), so every page reflows from 360px up without breakpoints.
  • Radii: 8 buttons · 10 inputs · 14 cards · 16–20 feature panels.
  • Shadows: cards 0 20px 50px rgba(11,31,58,.10); map pins 0 6px 16px rgba(11,31,58,.30).
  • Surfaces: white default, Cloud #F5F7FA for data/utility sections, Ivory #F7F3EC for human/testimonial sections, Navy for conversion panels. Max two tinted surfaces per page.
